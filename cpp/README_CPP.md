# Auto Adder C++ Desktop

Нативная C++/Win32-версия интерфейса для локальной работы с документами.

## Почему Win32

- Минимальный вес: без Electron, браузера и тяжёлых UI-фреймворков.
- Полностью локальная работа.
- Нет ИИ, облаков, API и сетевой отправки данных.
- Хорошая совместимость со слабыми Windows-устройствами.

## Что уже заложено

- Добавление нескольких целевых документов: `.docx`, `.pptx`, `.xlsx`.
- Отдельный выбор образца: удостоверение или паспорт.
- Визуальный список загруженных документов.
- Панель выбранного образца.
- Таблица полей, которые должны переноситься в документы.
- Журнал действий.

## Важное про автоматическое считывание паспорта/удостоверения

Если образец является фото или сканом, то автоматическое извлечение ФИО, номера, даты выдачи и других полей требует локального OCR, MRZ-парсера или считывания штрихкода. Это можно сделать без ИИ и без интернета, но отдельным локальным модулем.

Практичный безопасный путь:

1. Для паспортов использовать MRZ-зону, если она есть.
2. Для удостоверений использовать PDF417/QR/штрихкод, если он есть.
3. Если образец только картинка без машинной зоны, подключить лёгкий локальный OCR.
4. После извлечения показать поля пользователю для проверки.
5. Только после подтверждения переносить данные в выбранные документы.

## Сборка через MSVC

Откройте "Developer PowerShell for Visual Studio" и выполните:

```powershell
cd "C:\Users\user\Desktop\Все проекты тут\auto-adder\cpp"
.\build_msvc.bat
```

Готовый файл появится здесь:

```text
cpp\build\AutoAdder.exe
```

## Следующий технический шаг

Заполнение `.docx/.pptx/.xlsx` выполняет локальный Python-движок через Office Open XML. Для переноса этой логики полностью в C++ позже можно добавить маленькие локальные библиотеки:

- `miniz` или `libzip` для чтения Office Open XML архивов.
- `pugixml` для правки XML внутри документов.
- локальный OCR/MRZ/barcode-модуль только при необходимости.

Все эти модули могут работать полностью офлайн.
