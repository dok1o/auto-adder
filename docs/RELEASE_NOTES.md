# Auto Adder 0.3

## What's included

- Local extraction of identity fields from samples.
- Local filling of DOCX, XLSX, and PPTX templates.
- Test pack in `check_pack`.
- Privacy/security note for customers.
- Windows app icon embedded into `AutoAdder.exe`.
- Portable Python runtime included, so customers do not need to install Python.
- One-file installer creates a desktop shortcut and opens the app.
- Filled copies are created next to templates without creating `_backup` files or changing the source templates.

## Customer package

Use:

```text
AutoAdderSetup.exe
```

Suggested direct GitHub download link after publishing:

```text
https://github.com/OWNER/REPOSITORY/releases/latest/download/AutoAdderSetup.exe
```
